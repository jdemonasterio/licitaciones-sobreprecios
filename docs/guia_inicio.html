Esta guía te lleva, paso a paso y sin saber programar, desde una computadora Windows recién salida de la caja hasta tener la herramienta de sobreprecios andando, actualizándose sola todos los días, y con Claude Code disponible para pedirle mejoras cuando las necesites. 0

Qué es esto y qué vas a lograr

1 minuto de lectura

Esta herramienta compara lo que el Estado argentino pagó en una compra (alimentos, limpieza, librería) contra lo que costaba ese mismo producto en el mercado en esa misma fecha. Corre entera en tu computadora: no hay que subir nada a internet, no hay servidores de terceros, no hay que saber programar para usarla día a día.

Al final de esta guía vas a tener: la aplicación abierta en tu navegador, una clave gratis de inteligencia artificial cargada, los datos actualizándose solos todos los días, y un asistente (Claude Code) al que le podés pedir mejoras en español simple.

El recorrido completo son 15 etapas (0 a 14). Las etapas 1 a 7 instalan y usan la herramienta en sí — con eso ya podés trabajar. Las etapas 8 a 13 agregan Claude Code, para seguir mejorando el sistema sin depender de un programador. La etapa 14 es un glosario de consulta.

1

🖥️ Preparar la computadora

5 minutos

Qué vas a hacer: dejar la computadora lista: Windows actualizado, una carpeta fija para el proyecto, y saber abrir las dos ventanas que vas a usar todo el tiempo: el Explorador de archivos y la consola (cmd).

Por qué: si no sabés abrir estas dos cosas rápido, cada paso de acá en adelante te va a costar el triple.

Pasos

  1. Actualizá Windows. Tecla Windows → escribí Buscar actualizaciones → Enter → "Buscar actualizaciones" → instalá lo que haya y reiniciá si lo pide.
  2. Creá una carpeta "Proyectos". Abrí el Explorador de archivos (el ícono de una carpeta amarilla en la barra de tareas, o tecla Windows + E). Entrá a Escritorio o a Documentos, click derecho → Nuevo → Carpeta → nombrala Proyectos. Ahí va a vivir todo este proyecto.
  3. Practicá abrir la consola (cmd). Apretá la tecla Windows, escribí cmd, apretá Enter. Se abre una ventana negra con letras: esa es la consola. Es el lugar donde vas a hacer doble click en los .bat más adelante, o donde vas a escribir algún comando puntual.
Qué tenés que ver en pantalla: una ventana negra con un texto parecido a C:\Users\TuNombre> y el cursor titilando al lado. Ahí podés escribir comandos.
▶ Ver el video: 5 formas de abrir CMD en Windows 11
Si no ves el video: youtube.com/watch?v=TmJyTXZkwCw — "5 formas de abrir CMD en Windows 11" (Tuto Win10)

Problemas comunes

  • Si Windows Update tarda mucho o pide reiniciar varias veces, es normal: dejalo terminar antes de seguir con la Etapa 2.
  • Si no encontrás el ícono del Explorador, usá el atajo tecla Windows + E, siempre funciona.
✅ Validación de la etapa

Abriste una ventana de cmd (fondo negro, texto blanco) y tenés una carpeta Proyectos creada y vacía, lista para el próximo paso.

🐍 Instalar Python 3.12

5-10 minutos

Qué vas a hacer: instalar Python, el lenguaje en el que está escrita la herramienta. Es gratis y lo instala cualquiera, no hace falta saber programar.

Por qué: sin Python instalado, ninguno de los archivos .bat del proyecto va a funcionar.

Pasos

  1. Entrá a python.org/downloads desde el navegador.
  2. Hacé click en el botón grande que dice "Download Python 3.12.x" (si te ofrece una versión más nueva como 3.13 también funciona, pero si podés elegir, preferí la 3.12).
  3. Abrí el archivo descargado (termina en .exe, suele quedar en "Descargas").
  4. Esto es lo más importante de todo el paso: en la primera pantalla del instalador, abajo de todo, hay un tilde que dice "Add python.exe to PATH". Tildalo ANTES de tocar cualquier otra cosa.
  5. Con el tilde puesto, hacé click en "Install Now" y esperá a que la barra llegue al 100%.
  6. Cuando diga "Setup was successful", cerrá el instalador.
Qué tenés que ver en pantalla: una ventana gris con el logo de Python, un tilde SIN marcar que dice "Add python.exe to PATH" (marcalo), y más abajo un botón "Install Now".
Si te olvidaste de tildar la casilla, no pasa nada grave, pero después Windows no va a reconocer el comando python. El video de abajo explica cómo agregarlo a mano sin tener que reinstalar todo.
▶ Ver el video: Cómo agregar Python al PATH en Windows 11
Si no ves el video: youtube.com/watch?v=GmTG25Aoqvk — "Cómo agregar Python al PATH en Windows 11 (2026)" (divcode)

Cómo saber si ya lo tenés instalado

  1. Abrí cmd (Etapa 1).
  2. Escribí python --version y Enter.
  3. Si ves algo como Python 3.12.7, ya está. Si ves 'python' no se reconoce como un comando..., seguí los pasos de arriba.
✅ Validación de la etapa

Abrís cmd, escribís python --version y Enter. Tiene que decir algo como Python 3.12.x (no un error).

4

⚙️ Instalar el proyecto

2-5 minutos

Qué vas a hacer: correr instalar.bat, que prepara todo lo que la aplicación necesita para funcionar.

Por qué: esto crea un "entorno" de Python aislado para este proyecto (no toca ningún otro programa de tu computadora), instala sus dependencias y crea la base de datos con el catálogo de productos.

Pasos

  1. Abrí la carpeta del proyecto en el Explorador de Windows.
  2. Hacé doble click en instalar.bat.
  3. Se abre una ventana negra que muestra pasos del 1 al 5. Puede tardar unos minutos.
  4. Cuando termine, apretá cualquier tecla para cerrar la ventana.
Qué tenés que ver en pantalla: líneas como [1/5] Buscando Python 3.12... [2/5] Creando entorno virtual... [3/5] Instalando dependencias... [4/5] Preparando archivo .env... [5/5] Creando la base de datos y cargando el catálogo... y al final: "Listo! Proximos pasos: ..."
Puede aparecer un cartel azul "Windows protegió su PC" (SmartScreen) antes de dejarte correr el .bat. Es normal en un script nuevo, no es un virus: hacé click en "Más información" y después en "Ejecutar de todas formas".

Problemas comunes

  • Si aparece la palabra ERROR, leé el mensaje completo: te va a decir qué guía mirar. No cierres la ventana, copiá el texto o sacale una foto.
  • Si tu antivirus corporativo bloquea el .bat sin darte la opción de "ejecutar igual", pedile a IT que agregue una excepción para esta carpeta.
✅ Validación de la etapa

La ventana negra terminó mostrando "Listo! Proximos pasos:" sin ningún ERROR arriba, y ahora existe una carpeta .venv dentro del proyecto.

📅 Actualizar datos todos los días

10 minutos para programarlo (una sola vez)

Qué vas a hacer: dejar programado que la computadora corra actualizar_datos.bat sola, todos los días.

Por qué: no existe un archivo histórico público de precios de mercado 2023 en adelante. Cada día que no se corre el relevamiento es un día de precios que se pierde para siempre.

Correrlo a mano (para probarlo primero)

  1. Doble click en actualizar_datos.bat.
  2. Baja precios de hoy y busca compras nuevas de los últimos 60 días. Puede tardar bastante (descarga del Boletín Oficial + inteligencia artificial): es normal.
  3. Si el plan gratis de IA se queda sin cuota, el proceso sigue solo con reglas, no se traba.

Programarlo con el Programador de tareas de Windows

  1. Tecla Windows, escribí Programador de tareas, Enter.
  2. Click derecho en "Biblioteca del Programador de tareas" → "Crear tarea básica...".

  4. Desencadenador: elegí "Diariamente", y una hora en la que la computadora suela estar prendida (por ejemplo 9:00). Siguiente.

  6. En "Programa o script" hacé click en "Examinar..." y elegí el archivo actualizar_datos.bat dentro de la carpeta del proyecto.
  7. Siguiente → Finalizar.
Qué tenés que ver en pantalla: al terminar, la tarea nueva aparece en la lista del "Programador de tareas" con el nombre que le pusiste y "Diariamente" en la columna de desencadenadores.

🔒 Configurar los permisos de Claude Code

2 minutos (ya casi está hecho)

Qué vas a hacer: entender cómo Claude Code pide permiso antes de tocar archivos o correr comandos, y confirmar que este proyecto ya viene configurado con valores seguros para que no te pregunte lo mismo todo el tiempo.

Los 4 modos de permisos (en criollo)

ModoQué hace
NormalTe pregunta antes de cada cambio o comando. El más seguro, pero el más lento de usar.
PlanPrimero te muestra un plan de lo que va a hacer, vos lo aprobás, después lo ejecuta.
Aceptar ediciones (acceptEdits)Acepta automáticamente los cambios de archivo, pero sigue preguntando para comandos del sistema que no estén en la lista permitida. Este es el que ya viene configurado en este proyecto.
Saltar todo (bypassPermissions)No pregunta NUNCA, ni para borrar archivos ni para mandar nada a internet.
Nunca uses el modo "Saltar todo" (bypassPermissions). Ese modo le da a Claude Code vía libre para hacer cualquier cosa sin preguntarte, incluyendo borrar archivos o mandar datos afuera. Para este proyecto no hace falta jamás: el modo "Aceptar ediciones" ya es cómodo y sigue siendo seguro.

Ya está configurado para vos

Cuando corriste instalar.bat se creó el archivo .claude/settings.json (copia de docs/claude_settings_recomendado.json) con valores seguros ya puestos:

  • Modo por defecto: "Aceptar ediciones" — no te va a preguntar por cada línea de código que cambie.
  • Permitido sin preguntar: leer archivos del proyecto, correr los tests (pytest), correr los comandos propios de la herramienta (sobreprecios.cli), y los .bat del proyecto.
  • Bloqueado siempre (ni preguntando te lo deja hacer): leer tu archivo .env (ahí están tus claves), borrar la carpeta data completa, o mandar cambios a internet (git push).

No tenés que tocar nada de este archivo. Si en algún momento ves que Claude Code te pregunta antes de correr algo que no esperabas, está bien: significa que ese comando no estaba en la lista permitida, y es una decisión tuya aprobarlo o no.

En la terminal, podés cambiar de modo en cualquier momento apretando Shift+Tab. En la app de escritorio, el modo se elige desde un menú visible en la ventana de chat.
✅ Validación de la etapa

Entendés que "Aceptar ediciones" es normal y seguro para este proyecto, y que "Saltar todo" (bypassPermissions) no se usa nunca. El archivo .claude/settings.json existe en la carpeta del proyecto (si no está, volvé a correr instalar.bat).

💬 Cómo pedirle mejoras a Claude

lectura + práctica

Qué vas a hacer: abrir el proyecto en Claude Code y aprender a escribir un buen pedido.

Cómo escribir un buen pedido

  • Dale contexto. Si es sobre una compra puntual, pegá el link de esa página (ej. http://127.0.0.1:8000/licitacion/12).
  • Decí exactamente qué querés, no solo que "algo está mal".
  • Decile cómo vas a revisar que quedó bien (ver Etapa 13).

10 pedidos de ejemplo para copiar y pegar (para ESTE proyecto)

  1. Leé MEJORAS.md y hacé la mejora #19 (ampliar el catálogo de limpieza).
  2. Agregá el producto 'lentejas 500 g' al catálogo, en el rubro alimentos.
  3. Agregá un mayorista nuevo a la lista de fuentes de precios, se llama '<nombre>' y su página es '<url>'.
  4. La licitación de http://127.0.0.1:8000/licitacion/12 tiene mal el precio del renglón 2: dice $450 pero en el documento original dice $45. Arreglalo.
  5. Armame un reporte en texto de todas las compras de yerba mate del 2026, con el proveedor y el sobreprecio de cada una.
  6. ¿Por qué esta compra de leche en polvo aparece en rojo? Explicame el cálculo paso a paso, como si fuera para alguien que nunca usó la herramienta.
  7. El filtro de fecha en el webui no me deja poner un rango de más de un año, ¿lo podés arreglar?
  8. Revisá si hay algún producto del catálogo que nunca matchea con ninguna compra, y decime cuáles son.
  9. Bajame la última versión del proyecto desde GitHub. (esto corre git pull, solo funciona si bajaste el proyecto con Git en la Etapa 3, Opción B)
  10. Leé MEJORAS.md y hacé la mejora #8 (arreglar las rutas que ignoran LIC_DB_PATH/LIC_CACHE_DIR).
Siempre terminá cualquier pedido que toque código con: "corré los tests (python -m pytest -q) y el simulador (simular.bat)". Así Claude confirma que no rompió nada antes de darte el cambio por terminado.

Revisá siempre lo que te muestra

Claude Code te muestra qué archivo va a modificar y qué líneas cambian antes de guardarlo. Leelo, aunque sea por arriba. Si algo no te cierra, preguntale "¿por qué hiciste este cambio?" antes de aceptar. Si no entendés algo, pedile que te lo explique más simple.

Hacé un backup de la base antes de pedir cambios grandes. La base de datos está en data\sobreprecios.db. Copiala a otra carpeta con la fecha en el nombre antes de pedir cambios relacionados a datos (ver Etapa 13).
✅ Validación de la etapa

Le mandaste a Claude Code al menos un pedido de la lista de arriba (o parecido) y viste que te mostró los archivos que iba a cambiar antes de aplicarlos.

🐞 Cómo reportar un error a Claude

2 minutos

Qué vas a hacer: aprender las dos formas de juntar la información de un error para que Claude lo pueda entender y arreglar rápido.

Si el error pasó DENTRO de la aplicación (el navegador)

Esta aplicación ya tiene un botón pensado exactamente para esto, abajo de todo en cualquier pantalla.

  1. Abajo de la página, abrí "🐞 Reportar un problema (arma el texto para pegarle a Claude)".
  2. Completá "Qué esperaba" y "Qué pasó" con tus palabras, sin apuro.
  3. Click en "Copiar texto para Claude". Ya junta sola la dirección de la página, la fecha y hora, y lo que escribiste.
  4. Pegalo en el chat de Claude Code (Ctrl+V).

Si el error pasó en una ventana negra (instalar.bat, actualizar_datos.bat, etc.)

  1. Seleccioná el texto del error con el mouse (click y arrastrar) dentro de la ventana negra.
  2. Ctrl+C para copiarlo.
  3. Pegalo en el chat de Claude Code junto con una frase corta: qué esperabas que pasara y qué paso en cambio.

Siempre ayuda: una captura de pantalla

  1. Apretá Win + Shift + S (las 3 teclas juntas).
  2. La pantalla se oscurece un poco: marcá con el mouse la zona que querés capturar.
  3. Se copia sola al portapapeles: pegala en el chat de Claude Code con Ctrl+V.

Otro dato útil: la dirección exacta de la página

Hacé click una vez en la barra de direcciones del navegador (arriba de todo, donde dice http://127.0.0.1:8000/...), Ctrl+C para copiarla, y pegala junto con tu pedido. Así Claude sabe exactamente en qué pantalla pasó el problema.

Sabés dónde está el botón "Reportar un problema" en la aplicación, y cómo sacar una captura con Win + Shift + S.

🧪 Cómo saber que una mejora quedó bien

5 minutos por cambio

Qué vas a hacer: correr el simulador después de cualquier cambio importante, antes de confiar en él.

Pasos

  1. Doble click en simular.bat (o pedile a Claude que lo corra por vos).
  2. Abre un navegador invisible y recorre la aplicación como lo haría una persona real: filtra licitaciones, marca una revisión, arma un reporte, investiga un caso. No toca tu base de datos real.
  3. Al final te dice "Todo verde. OK para entregar esta versión." o te marca qué escenario falló.
  4. Si querés, abrí también iniciar.bat y mirá con tus propios ojos la pantalla donde se hizo el cambio.
Qué tenés que ver en pantalla: una tabla con una fila por escenario (Inicio, Detalle de licitación, Marcar revisión, Reportes...) y al final "Todo verde" o la lista de qué falló.

Si algo se rompió

  • Decile a Claude Code: "volvé al estado anterior". Si bajaste el proyecto con Git (Etapa 3, Opción B), puede deshacer el último cambio con precisión.
  • Si bajaste el ZIP (sin Git), el deshacer depende de que Claude recuerde el cambio anterior en la conversación — por eso conviene pedir cambios de a uno, no todos juntos.
Antes de un cambio grande relacionado a datos, copiá el archivo data\sobreprecios.db a otra carpeta con la fecha en el nombre (ej. sobreprecios_backup_2026-10-11.db). Si algo sale mal, cerrás la aplicación, reemplazás el archivo por tu copia, y la volvés a abrir.
✅ Validación de la etapa

Corriste simular.bat al menos una vez y vio "Todo verde" al final.

📖 Glosario mini

de consulta, no hace falta memorizarlo
Python
El lenguaje de programación en el que está escrita esta herramienta. Se instala una sola vez (Etapa 2) y después queda funcionando solo.
Terminal / consola / cmd
Una ventana negra donde se escriben comandos en vez de hacer click con el mouse. En Windows se abre escribiendo cmd después de apretar la tecla Windows.
Carpeta del proyecto
La carpeta que bajaste en la Etapa 3 (se llama algo como licitaciones-sobreprecios). Todo pasa adentro de ella.
Servidor local
El "motor" que hace funcionar la página web de la aplicación en tu propia computadora, sin internet. Se prende con iniciar.bat y se ve como una ventana negra que hay que dejar abierta.
Clave de API
Una contraseña larga que identifica tus consultas ante un proveedor (Google, OpenAI). La de este proyecto (Gemini) es gratis y se consigue con tu cuenta de Google.
Claude Code
Un asistente que puede leer y modificar el código del proyecto charlando en español normal, sin que necesites saber programar.
Test
Una verificación automática chiquita que confirma que una parte del programa sigue funcionando como se espera. Se corren todos juntos con python -m pytest -q.
Simulador
Un programa que abre un navegador invisible y usa la aplicación como lo haría una persona real, para avisar si algo se rompió antes de confiar en una versión nueva. Se corre con simular.bat.
